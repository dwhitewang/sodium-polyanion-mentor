# 颜色语义：从47条历史观察到原创角色方案

## 先问颜色要编码什么

样品、状态、物相、元素/位点、连续物理量是不同字典。同一面板指定一种主颜色变量，第二维优先用分面、线型、点形或直标。样品×温度的图，通常保持样品色，用行标题表示温度；样品×SOC用样品分面、节点色阶，不生成几十种无顺序颜色。

`data/colors.json` 的 `observed` 是47条**历史实看笔记的摘要**，保留DOI、行号、语义冲突和近似HEX。本次未重新打开图，未取得作者源色。`palettes` 是5套重新设计的原创方案；不能以其HEX声称来自某篇论文。

## 可直接使用的五类方案

用 `mentor.py palette <id>` 取完整角色、符号/线型、限制和数值预检。

| id | 用途 | 主要颜色/编码 |
|---|---|---|
| dual | 双样品核心比较 | 基准深蓝#24526B，干预赭红#B85940；圆/方＋实/虚线 |
| categorical | 基线/A/B/A+B | 深灰#3B454F、蓝#246C8B、绿#55764A、玫红#A64E64；四种点形/线型 |
| soc | 同材料有序取态节点 | 五级单向蓝阶；C-S2/D-S2等直标区分路径，不拿电压代替SOC |
| sequential | 非负连续强度/幅值 | 浅蓝到深蓝，统一数值范围/单位；缺测另用灰+NA |
| diverging | 有物理参考零点的有符号差值 | 蓝—近白—赭；零点固定、±和截断显式标出 |

默认S0–S4只是布局占位，不是实验SOC数值。可用 `mentor.py palette soc --labels "C-S1,C-S2,D-S2"` 返回1–5个真实状态ID的原创颜色；自定义标签模式仅编码离散身份，输入次序和颜色明暗不代表Na量或电压。若实际要用颜色编码SOC，先确认数值与排序，同SOC须同色，充放分支用空心/实心或线型区分；信息未定时优先状态分面，不直接套用渐变。工具只返回所选色值的数值预检，不认证物理状态顺序。顺序图不保证感知完全均匀；发散图灰度中两端可能接近，须加符号/等值线。所有方案未做色觉缺陷或印刷认证。亮度/白底对比度只检测部分风险，不能代替实际图的小尺寸审查。

### 四样品×三状态如何组合

默认三个状态分面，每个面板保留基线/A/B/A+B四种固定样品色与点形；图例全篇固定，不设计12种颜色。若改成四个样品分面且每面板叠加三条状态谱，保持该样品色，将实/虚/点划线只分配给状态，并直接标状态ID。此时停用categorical预设的样品线型，避免同一线型同时表示样品和SOC。必要对照不能为了减少颜色而删去。

## 从文献中保留的好做法与反例

- `10.1002/anie.202422732`：双工况身份色跨图持续，有助于镜像比较；拟合组分色另设图例，不能混成同一身份。
- `10.1002/adma.73081`：全系列筛选后收敛到核心双样品；收敛不能删除能识别因果的必要对照。
- `10.1016/j.ensm.2024.103861`：同一元素在不同图交换颜色的历史记录提醒，应建立全篇身份字典，不能各绘图文件各选各的。
- `10.1002/adfm.202511174`：暴露×改性四组可重新用样品色、暴露线型两维编码，避免无序四色承担两个变量。
- `10.1002/adfm.76558`：连续差值图应有明确零点/色域；筛选通过色与样品色是两种语义，不能无图例复用。

这些是信息设计借鉴，不复制原论文图片，也不背书所有源图规范。Matter/Joule目前没有本色库已完成条目；不得编造它们的特有配色风格。

## 实际应用四步

1. 列角色字典并与用户既有样品色协调；已稳定使用的角色不为换风格而随意改色。
2. 选择适配数据类型的方案。组间数值比较共色标与归一；若确需不同量程，分别明示，不能凭颜色亮暗排行。
3. 加符号、线型、状态ID和直接标签；灰色表示参照/辅助，不自动表示差、无信号或缺失。
4. 用真实线图/谱图/热图检查缩小后是否可辨。浅色适合背景和面积，细线宜加深。无原图时只交映射和待验证项，不宣称已通过最终图面检查。

预览 `assets/palette-preview.svg` 只示范原创角色与编码，不包含实验数据或文献图面。真正出图还要核坐标、比例尺、单位、误差与图注，不把配色改善当成科学证据改善。
