# 检索方法：从有边界的发现到可接续的阅读队列

这是检索与筛选工作流，不是宣称查全的按钮。计划、执行、纳入、正文阅读和方法迁移分别验收。当前只构建/调用方法时不恢复其他暂停目标。

## 1. 先固定这一次要解决的问题

区分快速找文、最邻近先例核查、主题地图和覆盖审计。沿用用户已给材料体系、时间、出版社/期刊档次、类型及全文范围，不重复询问；只有缺项会实质改变结果时才问。旧项目的2021-09-23—2026-09-23是历史冻结窗口，不自动成为未来“近五年”。明确采用首次在线日期还是卷期日期，未知日期保留待核。

本技能默认研究对象为**钠离子电池聚阴离子正极本身的改性**。作为对电极或测试平台出现不算目标研究；独立负极/电解液研究不扩入。新相发现、复合正极、补钠正极配方的边界按当前问题显式判断，不能仅凭标题里有phosphate就纳入。历史刊档限制只在用户继续该范围时沿用，不将个人期刊偏好变成普遍质量判断。

保存简短协议：研究问题、纳排、时间口径、来源计划、关键词族、已知应召回文献、停止条件。快速找几篇不必强制系统综述流程；宣称全面覆盖时才需要逐格覆盖、筛选计数和缺口审计。检索后改变范围记修订，不倒称事前预设。

## 2. 三条互补路线

**关键词路线。** 材料名字/通式/缩写分别检索，Na-ion/sodium与cathode/positive electrode交叉；NASICON包括常见拼写误差NASCION作为补漏词，不写进科学正文。先宽查材料，再按掺杂/占位/缺陷、包覆/复合界面、工艺/形貌、工作态/失效等问题族细分。标题未写modification不能直接排除；泛battery标题也不能仅因没有化学式而判对象外。

**刊源—时间分格。** 对要求覆盖的期刊用已核刊名/ISSN及年度或更细时间段补检，独立记录每格的返回数、分页/游标、唯一DOI、读取终止条件和未筛项。不要把同出版社网站引文当该出版社正文。稳定排序、API限额和分页方法须以当前官方说明/实际返回核验，不猜端点。

**种子—引文路线。** 用已确认相关的种子前向/后向扩展，验证主题关键词是否漏掉核心文献。种子未纳入但用于探索时标探索，不混为范围内证据。补漏发现新术语后回写检索式并记录修订。相同DOI被多个平台收录不是独立研究验证。

领域地图可分近期研究、经典背景、方法类比；只有当前任务允许才扩展时间或材料，分别标注，不把高被引背景淹没最新相关研究。所谓最近/首次/尚无人做需要当前检索证据，静态159条库不能保证。

## 3. 来源、访问与真实覆盖

优先当前可用的出版社原页与可核题录源互相校验。Crossref等题录可帮助DOI/日期/刊源核对，但摘要、方法、首次在线字段可能缺失；不能从题录长度推正文完成。搜索摘要和片段只用于发现/初筛，正式关键结论回原文。

OA采用当前授权的正常访问方式；订阅正文可通过用户已授权的机构浏览器访问，不将登录权限当开放许可。遇到验证、登录或提取故障记录实际状态；不得绕过权限，不重复无效刷新。工具版本变化不意味着用户未登录。不能把HTTP200但正文尚在Loading/预览的页当全文，也不能把403判为论文不存在。

真实检索保存来源、查询、执行日期、页次/游标、原始结果定位及可用时的哈希。原始快照和用户资料留在项目目录，不装进skill。下载/复制受版权材料服从访问许可与用户范围，默认不向用户交付论文原图。离线演示或合成数据不得进入真实检索数/已读数。

## 4. 去重和筛选不损失不确定性

第一层按规范化DOI去重：去URL前缀、大小写归一、去末尾普通标点。标题相近只提示人工确认，不自动合并；无DOI仍保留独立候选。更正、预印本、正式版显式关联，不把更正再算独立研究。

第二层按**对象—干预—年份/类型—刊源**筛选，保存具体理由和证据位置。候选、题录核验、摘要筛查、部分正文、正文完成、通用迁移允许是不同字段。之前已读但有公式缺口/归属隔离时只补相应缺口，不重计或静默解除隔离。

第三层形成问题地图：哪些策略处理同一瓶颈，如何设置对照，解释最强的先例是哪一篇，还缺哪种判别观察。相似度只是查先例信号，不直接裁定创新不存在；“未找到”也不是“没有人做”。

## 5. 本地工具：计划、筛选、接续

```text
python scripts/search_workflow.py plan --family nfpp --family nasicon --from-date 2024-01-01 --until-date 2026-09-23 --journal "Advanced Materials"
python scripts/search_workflow.py screen candidates.json --from-date 2024-01-01 --until-date 2026-09-23
```

日期为示例，不是当前任务默认窗口。`plan` 输出待执行的关键词族、来源角色、种子召回和记录字段，**不发网络请求**。实际执行由当前可用检索/浏览器工具完成，先确认权限与接口，不使用未经验证的旧API常量。

`screen` 输入为 `{"records":[{"doi":"...","title":"...","first_online":"YYYY-MM-DD或null","journal":"...","source":"...","locator":"..."}]}`，保留其他元数据。输出批内去重/重复来源、与159条库的交集、日期缺项/冲突和建议下一步；不根据标题自动认证研究资格，不输出“全文已读”。历史隔离项不回传科学内容。

阅读队列按当前问题相关性、已知缺口和目标期刊优先级安排，不以每篇被引或网页可开代替质量判断。计划生成或题录去重成功不表示已执行搜索。源源不断的无关新增结果不是继续扩范围的理由。

## 6. 什么时候可以收尾

用户指定数量/范围的短任务达到交付并说明限制即可。覆盖任务须核：计划分格哪些执行、已知种子召回是否漏掉、检索独立路线增量、筛选/唯一/待办数是否闭合、访问失败会否改变结论。可写“本次范围内已检索并处理这些条目，仍缺……”，不能保证所有索引无漏。

暂停时保存：协议/修订、已执行查询、原始定位、DOI去重表、当前文章读到哪里、具体缺项、下一可行动点。用户要求暂停就暂停，不因验证恢复或又发现一篇而自行重启。

阅读接续使用 [增量阅读](incremental-reading.md)：`发现→资格核验→按范围读完→抽象条件规则→更新知识/反例`。纯写作/组图组织建议不主动展开论文案例；依赖文献证据的创新/论证判断必须给对应DOI与支持范围，不给全文。库中没有支持时明示一般理论推演，不能以漏检等同不存在。
