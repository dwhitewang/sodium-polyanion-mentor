# 研究决策：从可成立的贡献到最小判别实验

## 1. 不把机制论文当唯一合格答案

先识别贡献类型：新现象/失效诊断、可证伪机制、条件式设计规则、可控合成方法、应用条件推进。可靠的工艺或功能改进可以成立，不必同时声称新自旋、熵稳定和界面协同。选与现有证据最贴合的一类，再提出能升级它的下一步。

创新句式：在【具体工况】下，【现有策略/材料】受【可测瓶颈】限制；我们通过【可控干预】改变【中间量】，预计【可区分预测】，同时检查【新代价】。不给空白项填未经测量的机制。

优先寻找四种入口：指标排序不一致；首圈与后续不同；同一变量的收益与代价交叉；已有解释对某对照预测失败。真实反例可帮助决定机制段写什么，比再增加一种改性元素更有区分力。规则P01、P02、P03、P12、P24。

## 2. 对照由问题产生，不由“高级仪器”产生

| 关键问题 | 最小有用比较 | 仍需警惕 |
|---|---|---|
| 两项处理是否各自必要 | 基线/A/B/A+B，或针对明确增量的删减对照 | 四组最高不自动证明超加和；剂量与共变要匹配 |
| 改善来自相纯度还是主相 | 相比例/碳匹配、回加、纯相近邻组成，分母分开 | 后混不重现共生界面 |
| 第二相直接储能还是接触作用 | 两端元、同配比物理混合、共生复合 | 经验加和基线与理论电子上限不同 |
| 过程变量是否导致终态差异 | 前驱体—中间态—成品，同温程/气氛/计量控制 | 终态均匀不证明成核或配体交换路径 |
| 位点/描述符可否预测 | 有定义的变量、剂量两端、留出组成/路线 | 事后拟合性能的指标不是独立预测 |
| 失效原因是否可干预 | 同失效指纹干预前后复验、拆解恢复分项控制 | 补液/换电极/补Na同时做不能唯一归因 |

不机械要求所有对照都做。选择结果最可能改变当前结论的一项，给出正、反、不明确三种结果的解释。涉及新增实验时区分文献报告条件、条件计算和探索建议；未核热史/浓度不生成伪SOP。

## 3. 检测的职责与不能跨越的边界

| 要约束的量 | 可配对的证据 | 不能直接推出 |
|---|---|---|
| 成分、相与占位 | 实际元素量＋定量相分析＋占位敏感探针 | 名义式即实际缺陷；无峰即绝对纯相 |
| 载流Na与电子库存 | 每式电子账＋状态元素谱＋Na局域/占位信息 | 总容量即某个位点贡献；峰数即电子数 |
| 局域结构与平均结构 | 元素分辨XAS/PDF与同状态衍射 | FT峰位即真实键长；平均环境即空间均匀 |
| 电子态与电导 | 状态/模型电子结构＋有碳/压实说明的直接输运 | DOS/光学带隙单独证明本征电导 |
| Na跳迁与长程输运 | 状态路径/瓶颈＋适用条件明确的GITT等 | 一条最低NEB即全网络扩散 |
| 体变、裂纹与界面 | 同反应深度原位结构＋匹配循环龄期成像/化学 | 终点恢复即零应变；少裂纹即已测应力 |
| 表面层的功能 | 形成前/后化学＋空间厚度/分布＋工作响应 | 某组分富集即致密、快离子、长期保护 |
| 反应时序与合成路径 | 热/气体/溶液时间轨迹＋分时固相/局域取样 | 静态配位数即交换速率；终态即过程证据 |

同源标签很重要：XAS→FT/WT；EIS→DRT/等效电路；同波函数→PDOS/ELF/电荷分析。不同表示可以互补，不能按图数算独立实验。模型参照、取样转移、探测深度和拟合假设随解释保留。

## 4. 四本账，只核相关的

**组成/电荷。** 名义投料、ICP整体、主相精修、局域价态分栏。按完整子晶格归一；空位、氧非化学计量、Na库存和价态有多种补偿路径。电中性给约束，不认证唯一缺陷身份。多元素、理想构型熵、真实随机性和熵稳定分开。

**容量/能量。** 可逆电子数为各中心系数×有证据的价态跨度；Q_th=nF/(3.6M)，M以g/mol计。含碳/复合粉体/两极活性/整芯分母不能互换。能量由同次放电积分，平均电压不是最高平台。相容量按质量加权只是给定条件基线，超过它不自动证明界面机制。

**状态/时间。** 样品、实际Na量或SOC定义、方向、圈次、温度、静置、取样史构成比较主键。同电压不保证同SOC；首圈回程不代表长循环；低温室温充/冷放不代表低温双向充放。

**工艺/器件。** 碳量/结构、粒径/孔隙、负载、热史、电解液、N/P与预钠化按作用范围记录。电极侧外部条件只用于约束正极结论，不自动扩展为负极/电解液研发。短脉冲不等于全流程短，粉末密度不等于整芯体积能量。

## 5. 科学判断的输出强度

- 观察：“在所测工况下观察到……”。
- 非唯一解释：“与……相容/支持……，仍需区分……”。
- 判别性证据：“在匹配……后，干预使……，从而排除了所检验的……解释”。不以一个对照宣布所有可能机制已排除。
- 探索方案：“若……为主导，则……；建议先……，出现相反结果时改写为……”。

规则与公开方法例通过 `mentor.py query` 内部查找；需要精确配方/数值时回核原文。需要证据的创新/论证建议必须给对应DOI及其支持范围；纯写作与组图组织建议不必附，案例按需展开，不提供全文。一般理论推演若未找到直接文献支持，明确标注其缺口，不由相似论文代证。此参考是跨文献原创归纳，不是某篇论文全部结论的背书。
